# Рефакторинг API создания чеков

## ✅ **Выполненные изменения:**

### 1. **Удалены дублирующиеся эндпоинты**
- ❌ Удален `POST /receipts` (старый базовый метод)
- ❌ Удален `POST /receipts/manual` (ручное создание админами)
- ❌ Удален `POST /receipts/test-cashback` (тестовый чек)

### 2. **Создан единый эндпоинт**
- ✅ **`POST /receipts`** - теперь единственный способ создания чеков
- ✅ **Редактируемый в Swagger** - можно вводить данные через UI
- ✅ **Автоматический кешбек** - всегда рассчитывается и начисляется

### 3. **Очищен код**
Удалены из `ReceiptsService`:
- ❌ `create()` - старый базовый метод
- ❌ `createManual()` - ручное создание
- ❌ `createTestReceiptForCashback()` - тестовый чек

Добавлен в `ReceiptsService`:
- ✅ `createReceiptWithCashback()` - единый метод с кешбеком

## 🎯 **Новая структура API:**

### Единственный эндпоинт создания:
```
POST /receipts
```

**Swagger документация:**
```yaml
summary: "Создать чек"
description: "Создает чек с автоматическим расчетом и начислением кешбека"
responses:
  201: "Чек создан, кешбек рассчитан и начислен"
  400: "Ошибка создания чека"
```

**Тело запроса (редактируемое в Swagger):**
```json
{
  "customerId": 1,
  "promotionId": "x-pharm",
  "number": 12345,
  "price": 1000,
  "date": "2024-01-20T10:00:00Z",
  "status": "success",
  "address": "ул. Пушкина, д. 10",
  "products": [
    {
      "productId": 1,
      "offerId": 1,
      "cashback": 50
    }
  ]
}
```

**Ответ (как у тестового чека):**
```json
{
  "message": "Receipt created successfully for customer Иван",
  "receipt": {
    "id": 8,
    "date": "2024-01-20T10:00:00.000Z",
    "number": 12345,
    "price": 1000,
    "cashback": 100,
    "status": "success",
    "products": [...],
    "customer": {...},
    "promotion": {...}
  },
  "summary": {
    "customerId": 1,
    "customerName": "Иван",
    "promotionId": "x-pharm",
    "totalPrice": 1000,
    "totalCashback": 100,
    "productsCount": 1,
    "offersApplied": 1
  }
}
```

## 🚀 **Преимущества:**

1. **Простота** - один эндпоинт вместо трех
2. **Консистентность** - всегда одинаковый формат ответа
3. **Автоматизм** - кешбек всегда рассчитывается
4. **Удобство** - полностью редактируемый в Swagger UI
5. **Чистота кода** - убрано дублирование

## 🧪 **Тестирование:**

1. Откройте Swagger UI: `http://localhost:3000/api`
2. Найдите `POST /receipts`
3. Нажмите "Try it out"
4. Отредактируйте JSON в поле ввода
5. Выполните запрос
6. Проверьте, что кешбек начислен: `GET /cashback/customer/history`

## ✅ **Результат:**

**Теперь есть один универсальный, редактируемый эндпоинт для создания чеков с автоматическим начислением кешбека!** 🎉
