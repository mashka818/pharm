## 📋 API Endpoints

### Существующие (улучшенные):
```
POST   /receipts/manual           - Ручное создание чеков (админы)
GET    /cashback/history/today    - История кешбеков
PUT    /cashback/:id/cancel       - Отмена кешбека
POST   /fns/scan-qr              - Сканирование QR
```

### Новые:
```
GET    /admin/notifications                - Уведомления
PUT    /admin/notifications/:id/read       - Отметить как прочитанное
GET    /admin/notifications/unread-count   - Количество непрочитанных
GET    /admin/stats/scanning               - Статистика сканирования
```
