## 🏗️ Новые API эндпоинты

### Админские уведомления:
```
GET    /admin/notifications              - Получить уведомления
PUT    /admin/notifications/:id/read     - Отметить как прочитанное
PUT    /admin/notifications/read-all     - Отметить все как прочитанные
GET    /admin/notifications/unread-count - Количество непрочитанных
```

### Статистика:
```
GET    /admin/stats/scanning             - Статистика сканирования чеков
```

### Кешбеки (существующие):
```
GET    /cashback/history/today           - История за день
PUT    /cashback/:id/cancel              - Отмена кешбека
GET    /cashback/customer/history        - История клиента
GET    /cashback/stats/today             - Статистика
```

## 🗃️ Новые таблицы и поля БД

### Таблица `admin_notifications`:
```sql
id              STRING    -- UUID уведомления
type            ENUM      -- Тип: suspicious_activity, repeated_scan, fake_receipt, system_error
title           STRING    -- Заголовок
message         STRING    -- Сообщение
promotionId     STRING    -- Подсеть
customerId      INT?      -- Клиент (если применимо)
fnsRequestId    STRING?   -- Запрос к ФНС (если применимо)
metadata        JSON?     -- Дополнительные данные
isRead          BOOLEAN   -- Прочитано ли
createdAt       DATETIME  -- Дата создания
```

### Расширение таблицы `offers`:
```sql
isLottery       BOOLEAN   -- Участвует в розыгрыше
lotteryPrize    STRING?   -- Описание приза
lotteryWinners  INT?      -- Количество победителей
lotteryEndDate  DATETIME? -- Дата окончания розыгрыша
```

### Расширение таблицы `receipt_products`:
```sql
fnsProductName     STRING?  -- Название из ФНС
fnsProductPrice    INT?     -- Цена из ФНС
fnsProductQuantity DECIMAL? -- Количество из ФНС
fnsProductSum      INT?     -- Сумма из ФНС
```
