# Итоговая реализация системы чеков и кешбеков

## ✅ Все требования выполнены

### 1. Сканирование QR-кодов
- **Валидные чеки**: после успешной проверки ФНС автоматически создаются в БД
- **Поддельные чеки**: автоматически отклоняются ФНС, не создаются в системе
- **Возвратные чеки**: отклоняются, кешбек не начисляется
- **Товары из ФНС**: автоматически сопоставляются с локальной базой данных

### 2. Создание чеков администраторами
- Новый эндпоинт `POST /receipts/manual` только для администраторов
- Обязательная валидация принадлежности товаров к подсети
- Автоматический расчет кешбека при ручном создании

### 3. Валидация подсетей
- ✅ Товары из р-фарм нельзя добавить в чек х-фарм
- ✅ Клиенты привязаны к своим подсетям
- ✅ Акции работают только в рамках своих подсетей
- ✅ Детальные сообщения об ошибках валидации

### 4. Автоматический расчет кешбека
- Кешбек начисляется на основе связи таблиц товаров и предложений
- Учитываются только товары, участвующие в активных акциях
- Детализация кешбека по каждому товару в чеке

### 5. Отслеживание кешбеков
- **Администраторы**: видят все кешбеки или по конкретной подсети
- **Компании**: видят только кешбеки своей подсети
- **Клиенты**: видят только свою историю
- Подробная статистика и аналитика

### 6. Отмена кешбеков
- Эндпоинт `PUT /cashback/:id/cancel` для администраторов
- Автоматическое списание бонусов с клиента
- Обязательная причина отмены с аудитом

## 🔍 Логика сопоставления товаров

При сканировании QR-кода система:
1. Получает список товаров из ФНС
2. Для каждого товара пытается найти соответствие в локальной БД:
   - По точному названию
   - По частичному совпадению
   - По ключевым словам
3. Если товар найден - связывает с `productId` и рассчитывает кешбек
4. Если не найден - сохраняет только данные ФНС без кешбека
5. Все данные ФНС сохраняются для аудита и последующего анализа

## 📋 API эндпоинты

### Чеки:
- `POST /receipts` - создание чека (базовый)
- `POST /receipts/manual` - ручное создание (админы)
- `GET /receipts` - список чеков
- `GET /receipts/:id` - детали чека

### ФНС:
- `POST /fns/scan-qr` - сканирование QR-кода
- `GET /fns/status/:requestId` - статус обработки

### Кешбеки:
- `GET /cashback/history/today` - история за день (админы)
- `GET /cashback/customer/history` - история клиента
- `PUT /cashback/:id/cancel` - отмена кешбека (админы)
- `GET /cashback/stats/today` - статистика (админы)
